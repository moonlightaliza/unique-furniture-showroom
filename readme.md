# 🪑 Unique Furniture Showroom

A modern, responsive business landing page developed for **Unique Furniture Showroom**, a furniture business located near DHQ Lodhran.

This project is being developed as part of an internship assessment for Orion Vision.

---

## 📌 Project Overview

The goal of this project is to create a clean, responsive, and user-friendly website that showcases the business, its products, and contact information.

The website is being built using only front-end web technologies.
